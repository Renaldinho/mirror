1. DESKTOP / TERMINAL
--------------------
Menu -> Settings -> Desktop mode opens the mirror in a normal browser window.
Use the Pi desktop's network icon to connect to Wi-Fi.
Return with Settings -> Return to kiosk, or the Mirror shortcut on the desktop.

On the Pi keyboard: Alt + F4 closes the mirror, then Ctrl + Alt + T opens a terminal.
Without a Pi keyboard, use SSH from another computer (section 3).

2. USERNAME, DEVICE NAME, IP, PASSWORD
------------------------------------
Run on the Pi:
  whoami          # username
  hostname        # device name
  hostname -I     # IP addresses

Passwords cannot be displayed. Password entry shows no characters while typing.
Change your account password:
  passwd

Reset it if you still have sudo access:
  sudo passwd "$(whoami)"

3. CONNECT FROM WINDOWS
----------------------
On the same network, open PowerShell:
  ssh renars@raspberrypi.local

If that name fails, replace YOUR_PI_IP with the current IP from section 2:
  ssh renars@YOUR_PI_IP

Use the username from whoami if it is not renars. Enter the Pi account password.
Leave SSH with:
  exit

4. UPDATE THE MIRROR
--------------------
Renars must commit and push changes first. On the Pi:
  cd ~/mirror
  bash deploy/pi/update.sh --force --reboot

If the folder is missing, use cd ~/mirror-agent instead.
Run the update WITHOUT sudo; it asks for sudo when needed.
Wait for the rebuild to finish. SSH disconnects when the Pi reboots.
Git pull alone does not install the new app.

Update without rebooting:
  bash deploy/pi/update.sh --force

Then press Ctrl + Shift + R in the kiosk to reload.
If update.sh is missing, run this from the repo folder first:
  git pull --ff-only origin main

5. CLOSE / REOPEN / RELOAD
-------------------------
Close the kiosk over SSH:
  pkill -f '[c]hromium.*mirror/chromium'

Reopen it from a terminal ON THE PI DESKTOP:
  nohup /opt/mirror/bin/mirror-kiosk > ~/mirror-kiosk.log 2>&1 < /dev/null &

The launcher needs the desktop session. From SSH, reboot instead (section 9).
Ctrl + R reloads the kiosk; Ctrl + Shift + R bypasses the browser cache.

6. VOLUME AND BRIGHTNESS
-----------------------
Menu -> Settings: volume/mute for games and alarms, and UI brightness (minimum 20%).
Spotify has its own device-volume slider in Now Playing.
Use the monitor's buttons to change its actual backlight brightness.

Unmute the Pi and set system volume to 100%:
  wpctl set-mute @DEFAULT_AUDIO_SINK@ 0
  wpctl set-volume @DEFAULT_AUDIO_SINK@ 100%

If wpctl is unavailable, use the desktop sound controls.

7. DISCONNECT SPOTIFY
--------------------
Expand Now Playing and click Disconnect at the bottom.
Spotify's browser session may still be signed in when you reconnect.

8. TROUBLESHOOTING
------------------
Check services (both should show active/running):
  systemctl status mirror-api nginx --no-pager

Check the API (expected: "status":"ok"):
  curl -fsS http://127.0.0.1/api/health

Recent backend logs:
  sudo journalctl -u mirror-api -n 100 --no-pager

Live backend logs (Ctrl + C stops watching):
  sudo journalctl -u mirror-api -f

Browser log from the launcher above:
  cat ~/mirror-kiosk.log

Save diagnostics to the desktop to send to Renars:
  /opt/mirror/bin/mirror-diagnose > ~/Desktop/mirror-diagnostics.txt 2>&1

Restart the services, then reload the kiosk:
  sudo systemctl restart mirror-api nginx

If an update reports local changes, run these from the repo folder and send
Renars the output before discarding anything:
  git status --short
  git diff

Check the current commit:
  git log -1 --oneline

9. RESTART / SHUT DOWN
---------------------
Restart:
  sudo reboot

Shut down, then wait for shutdown to finish before unplugging power:
  sudo poweroff

10. TERMINAL SHORTCUTS
---------------------
Ctrl + Shift + C   Copy selected text.
Ctrl + Shift + V   Paste.
Ctrl + C           Stop a command or live log view.
